🧠 1. Como o Python Decide Qual Operação Usar?

Clique nas opções para ver o caminho exato que o interpretador Python percorre:

if opcao not in ("1", "2", "3", "4", "5"): print("⚠️ Opção inválida!"); continue
if opcao == "1": resultado = somar(num1, num2); simbolo = "+"
elif opcao == "2": resultado = subtrair(num1, num2); simbolo = "-"
elif opcao == "3": resultado = multiplicar(num1, num2); simbolo = "*"
elif opcao == "4": resultado = dividir(num1, num2); simbolo = "/"
elif opcao == "5": resultado = porcentagem(num1, num2); simbolo = "%"

🔬 2. O Código Isolado das 5 Operações

1. Soma 
def somar(a, b):
    return a + b
2. Subtração 
def subtrair(a, b):
    return a - b
3. Multiplicação 
def multiplicar(a, b):
    return a * b
4. Divisão com Trava de Zero 
def dividir(a, b):
    if b == 0:
        raise ZeroDivisionError("Não divide por 0")
    return a / b
5. Porcentagem (%) 
def porcentagem(valor_base, taxa_percentual):
    return (valor_base * taxa_percentual) / 100

            float
            
Número decimal com vírgula/ponto (ex: 3.14, 10.5). Permite números fracionados.

Cria um loop infinito para o menu continuar rodando até a pessoa digitar '0' (sair).

          

          

            try ... except
            
O airbag do programa! Se o usuário digitar letras no lugar de números, o código não trava.

          

          

            return
            
Devolve o cálculo feito dentro da função para quem chamou poder guardar ou exibir.
