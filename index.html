🧠 1. Como o Python Decide Qual Operação Usar?

Clique nas opções para ver o caminho exato que o interpretador Python percorre:

if opcao not in ("1", "2", "3", "4"): print("⚠️ Opção inválida!"); continue
if opcao == "1": resultado = somar(num1, num2); simbolo = "+"
elif opcao == "2": resultado = subtrair(num1, num2); simbolo = "-"
elif opcao == "3": resultado = multiplicar(num1, num2); simbolo = "*"
elif opcao == "4": resultado = dividir(num1, num2); simbolo = "/"

🔬 2. O Código Isolado das 4 Operações

1. Soma 
def somar(a, b):
    return a + b
2. Subtração 
def subtrair(a, b):
    return a - b
3. Multiplicação 
def multiplicar(a, b):
    return a * b
4. Divisão com Trava de Zero 
def dividir(a, b):
    if b == 0:
        raise ZeroDivisionError("Não divide por 0")
    return a / b

📖 Dicionário do Iniciante: Termos Técnicos Traduzidos

        

          

            float
            
Número decimal com vírgula/ponto (ex: 3.14, 10.5). Permite números fracionados.

          

          

            while True
            
Cria um loop infinito para o menu continuar rodando até a pessoa digitar '0' (sair).

          

          

            try ... except
            
O airbag do programa! Se o usuário digitar letras no lugar de números, o código não trava.

          

          

            return
            
Devolve o cálculo feito dentro da função para quem chamou poder guardar ou exibir.

          

          

            break
            
Quebra o laço de repetição imediatamente quando o usuário escolhe a opção 0.

          

          

            if __name__ == '__main__':
            
Garante que a calculadora só execute se você rodar o arquivo diretamente.

          

        

      

    


    
    

      

        
🎨 Guia de Personalizações Práticas

        

          

            1. Limitar a 2 casas decimais (:2f)
            
Troque print(f"{resultado}") por print(f"{resultado:.2f}") para exibir 3.33 em vez de 3.3333333335.

          

          

            2. Adicionar Potência (a ** b)
            
Crie a função def potencia(a, b): return a ** b e adicione no menu como opção 5.

          

          

            3. Salvar Histórico
            
Crie historico = [] e dê historico.append(f"{a} + {b} = {resultado}") após cada conta.
